## Independent reproduced defects and remediation

1. Archive timestamp `1e-999999999` hangs in both baseline validator/importer. Reviewed digit-bounded conversions fix that. A second independent pass found validator `0e999999999` / `-0e999999999` still hangs: two bounded subprocess regressions failed before the audit fix; all six import/audit exponent cases now pass. Zero is handled before exponentiation, preserving Decimal and microsecond/millisecond rules.
2. The new agent contention regression held a different advisory key because it used literal backslash-zero instead of NUL. Corrected against production hashing; mandatory JUnit gate increased from nine to ten cases.
3. Fail-fast `pg_try_advisory_lock` regressed existing concurrent source and identical-archive imports. First candidate CI failed both tests on Linux/PostgreSQL18 and elsewhere. Final code restores serialization using `pg_advisory_lock`, bounded by existing server lock timeout 15s and statement timeout 120s. Only LockNotAvailable is mapped to TimeoutError with its cause. No fixed delays or timeout increases.
4. Baseline malformed book IDs/nonfinite levels/partial mutation could retain valid state. Reviewed PR #7 rejects them and clears state. Transport injection verifies fresh snapshot after reconnect, including an increasing first delta (`u=15, seq=26`) that ordinary monotonic checks alone would accept.
5. Remaining book recovery defect: invalid delta clears validity but does not reconnect/resubscribe. A subsequent healthy delta on the same socket cannot recover. Separate fault probe confirms only initial snapshot publishes, one connection remains and state stays invalid. Connected silent feeds also rely on freshness invalidation without automatic reconnect. **Autonomous recovery remains NO-GO.** No false-valid state was observed in the fixed code.
6. Baseline collector.stop could acknowledge before its executor DB write finished. Reviewed drain helper retains ownership through repeated cancellation, commit/rollback and failure retrieval. Independent audit also found monitor schema initialization used bare to_thread; service.close now drains it. The existing final Qt thread already waits shutdown_default_executor: this evidence must not be described as proven writes after process exit.
7. Public unauthenticated application REST GET (probe at a43ed74; TLS/HTTP source unchanged in tested 1390127) /v5/market/time succeeded with HTTP200/retCode0, TLS1.3 and certificate/hostname verification. No CA/trust/verification changes. Historical TLS failure root cause remains UNKNOWN; no claim it is fixed on the separate PC.
